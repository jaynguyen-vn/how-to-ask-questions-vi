# Vietnamese Smart Questions HTML

## Goal
Build a standalone Vietnamese HTML page that presents the core content of Eric S. Raymond and Rick Moen's "How To Ask Questions The Smart Way".

## Scope
- Create `index.html`.
- Include prominent source link and translation timestamp, per source copying policy.
- Present the material as a readable Vietnamese guide with sections, checklist, examples, and quick reference.

## Constraints
- Keep implementation simple: plain HTML, CSS, and minimal JavaScript if needed.
- No build tool unless required.
- Do not redistribute as an exact unattributed copy.

## Validation
- Verify HTML file exists and has no obvious duplicate IDs.
- Confirm source attribution and timestamp are present.
